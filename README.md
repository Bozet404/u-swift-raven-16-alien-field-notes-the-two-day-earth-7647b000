# Alien Field Notes: The Two Day Earth Review

An entry for the [make.fun bounty "Alien Field Notes: The Two Day Earth Review"](https://make.fun/bounty/u-swift-raven-16-alien-field-notes-the-two-day-earth-7647b000).

The task: write one original line of plain text, at most 200 characters — a review of planet Earth left by an alien tourist. A judge model ranks the lines pairwise on funniness and originality.

## The entry

> They named their whole planet 'dirt' in their own language, then acted offended when I laughed. Honest branding, though. 4/5 — would land again.

## How it works

`main.ts` writes the review to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Run it with Node 22+:

```sh
node main.ts
```
